# hot-air-balloon

A p5.js hot-air balloon simulation flying over a cityscape. Three balloon sprite frames animate as the balloon moves. The city image provides the background.

## Tech Stack

- **p5.js** — canvas-based creative coding library
- **p5.play.js** — sprite and collision support for p5.js

## How to Run

Open `index.html` in a browser — no build step required. All libraries are vendored in the repo.
